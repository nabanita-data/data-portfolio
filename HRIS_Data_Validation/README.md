# HRIS Data Validation Project

This project demonstrates how to build a simple HR data validation pipeline in Python using Faker and Pandas.

## Highlights
- Generates synthetic HR employee and department datasets
- Runs automated data quality checks such as missing IDs, duplicates, invalid emails, salary range, date logic
- Exports a structured JSON validation report

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells from top to bottom.
3. The final output shows a summary of validation checks and creates `reports_summary.json`.

## Technologies
Python, Pandas
